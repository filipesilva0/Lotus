Talk with Lotus on a voice call that remembers you, transcripts that stay in the language you spoke (with Translate), whole texts turned into stories, image resolution, ready-made prompts on every page, and a tidier Settings.

## New
- **Voice → Call**: a new first tab on the Voice page. Press the green button and talk; Lotus answers aloud when you pause and starts speaking while it is still writing. Mute, Interrupt and End are under the face. Calls remember what matters across calls and chats (turn Memory off for a call that shouldn't be kept), and past calls are listed in the sidebar to read again, summarize in Chat or call again.
- **Translate transcripts**: Speech to Text now writes what was said in the language it was said in. Translate asks the chat model for any language; switch between the original and its translations, and copy, download, read aloud or open either in Chat.
- **Stories from a whole text**: paste or open a chapter, an article or any text, and every paragraph becomes its own line with its own voice, speed, track, start and volume. "Name:" at the start of a paragraph changes the speaker. Script mode is still there.
- **Image resolution**: next to the aspect ratio, choose Model Default or 512 to 2048. Lotus shows the megapixels and tells you when a size is far from what the model was made for.
- **Example prompts**: Chat, Work and Images open with complete examples by category ("Act as a senior code reviewer…", "Research the best…", portraits, watercolours, app icons…). A click fills the box; nothing is sent.

## Changed
- **Settings**: the Models pane is now General. Temperature, context window, system prompt and the other per-chat model settings are only in Chat's right panel (Model), where they apply. Settings that did nothing were removed. The island lists the models of the engine you use, and Read Replies Aloud uses Lotus's own voice.

## Fixes
- **Speech to Text wrote Portuguese (and other languages) in English**: the language setting started on English, which makes Whisper write English. It now detects the language by itself; installs that still had the old default are moved to it once.
