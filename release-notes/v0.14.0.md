Lotus can now remember your "yes": press Always Allow on a permission request and it stops asking for that tool in that folder or on that website. Tasks and routines now run in Lotus's background service, and a new Activity tab in Tasks shows everything Lotus's agent has done, step by step.

## New
- **Always Allow**: permission requests in Chat, Work, Tasks and on the island have a third button. It remembers the tool for that folder (and everything inside it) or for that website. Things without a folder or site (clicking on your screen, for example) are remembered for the tool itself. Settings → Tools lists what you allowed; remove one to be asked again. Never allow rules still come first, and emptying a file always asks.
- **Activity** (Tasks → Activity): every run of Lotus's agent, from Chat, Work, the island, voice calls, tasks and routines. Filter by where it came from, search what was asked or answered, and open a run to see each step with its real result. A task's history button and a routine's "Steps in Activity" open just their runs.

## Changed
- **Tasks and routines run in Lotus's background service** instead of the main window. Every step of a task, and every routine, is a full run of the agent with its tools, so they can read and save files, add tasks and search the web like Chat does. They still run only while Lotus is open (also when it is hidden in the tray).
- **The task board is stored in its own tables** in Lotus's database instead of one big saved value. Your tasks, routines and their run history are moved over the first time 0.14.0 starts.
- The agents count at the bottom of Tasks now includes the tasks and routines that are running or waiting.

## Fixes
- A routine that adds a card or a task now keeps a link to the run that made it.
