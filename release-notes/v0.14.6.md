Web search in Work no longer fails when several agents search at the same time.

## Fixes
- **Web search with DuckDuckGo**: when Work's agents searched at once, DuckDuckGo answered all but the first with a captcha ("returned no readable results"). Lotus now sends searches one after another with a short pause, lets agents that ask the same thing share one search, reuses a search's results for 10 minutes, tries DuckDuckGo's lightweight page when the normal one is refused, and waits 20 seconds before one more try. SearXNG works as before.
