Think mode, tasks, routines and voice calls can now use Lotus's tools (files, tasks, memory, images, the web when it's on), with the same permission requests and honesty check as Chat. You can also use your own LM Studio, llama-server or vLLM, with an access key if it needs one.

## New
- **Think mode does things**: with Think on, Lotus first works out what you asked, then does it with its tools, then checks its answer against what really happened and fixes it if something is missing.
- **Tasks and routines use tools**: a task assigned to Lotus, or a routine, can read and save files, add tasks, remember things and make images. When one needs your permission, it shows at the top of the Tasks page (and on the island) with Allow and Deny.
- **Voice calls use tools**: ask for a task, a note or a reminder during a call and Lotus does it, then says so in a sentence or two.
- **Your own server**: Settings → Engines → Chat engine → "Your server" works with llama-server, LM Studio and vLLM. It lists the server's models, has an optional access key, and uses the server's own tool support (falling back to Lotus's method if the server refuses).

## Changed
- **Permission requests in Chat and Work wait for you** until you answer or press Stop (they used to give up after 15 minutes). Tasks and routines still give up after a while, and now say plainly that nobody answered.
- **Emptying a file always asks first**, even with "Never ask" on.
- **The honesty check counts**: if Lotus says "I added 4 tasks" but only added 1, it's asked to fix that. It also catches claims to have scheduled, deleted or installed something when it didn't.
- **Frequency and presence penalty** in Chat's Model panel now reach the model.

## Fixes
- **ComfyUI Desktop** is found on its own port (8000) as well as the usual one (8188), and Lotus switches to whichever answers.
- **A new install with no saved settings** uses Lotus's own engines everywhere. Before, some parts (tools, images) quietly expected Ollama and ComfyUI.
- **File paths with a line break in them** are refused instead of creating odd file names.
