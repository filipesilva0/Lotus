On Windows, Lotus can now use your microphone: Dictate, voice calls, Talk mode and the island's dictation said no microphone was found because Lotus never actually asked Windows for one.

## Fixes
- **Microphone on Windows**: the window engine Lotus runs in (WebView2) was left waiting for a permission prompt that never appeared, so the request ended before it reached Windows. Lotus now answers it itself for its own pages (the main window and the island). Windows' privacy settings still decide: if "Let desktop apps access your microphone" is off, Lotus says so. After the first use, Lotus shows up under Settings → Privacy & security → Microphone like other desktop apps.
- When the microphone still can't start, the message now ends with the exact error and how many microphones Lotus could list, so a report says what went wrong.
