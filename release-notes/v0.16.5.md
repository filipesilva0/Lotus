Web questions get an answer again, and Work research no longer makes up its sources.

## Web questions always get an answer
- When a model kept searching until it ran out of steps, Lotus used to stop with "I stopped… without a final answer". Now it asks the model to answer from what it already found, and says plainly if something couldn't be found.
- A question now gets at most five searches. After that, the model is told to stop searching and answer.

## Honest Work research
- Each helper agent now hands back the web pages it really found, so the final document can point to real sources.
- If no sources were found, Lotus says so. It won't save a document with made-up links or a reference list it has nothing to back up: the model is asked to fix it, and if it doesn't, Lotus takes them out and adds a short note.
- Lotus no longer says a job is done "with a reference list" when nothing was found.

## Better search results
- When DuckDuckGo asks for a captcha and Lotus switches to Bing, pages that have nothing to do with your question are now left out, and Lotus asks the next search site instead.
