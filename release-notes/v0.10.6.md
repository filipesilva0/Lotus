Chat and images work again on Macs: chat no longer stops with "exceeds the available context size", and images no longer run out of memory while a chat model is loaded.

## Fixes
- **Chat failed on every message** ("request exceeds the available context size (4096 tokens)"): the built-in chat engine now always starts with room for at least 8K tokens (Lotus's own instructions and tools take about 5K). When a long conversation outgrows it, Lotus restarts the engine with a bigger context and carries on instead of failing.
- **Images ran out of memory on Macs** ("Insufficient Memory … kIOGPUCommandBufferCallbackErrorOutOfMemory"): on Macs with 32 GB or less, Lotus now unloads the chat model before making an image (chat and images share the same memory there; chat loads again on your next message) and decodes the image in tiles. If an image still runs out of memory, Lotus tries once more with its low-memory settings before giving up, and the message now says plainly what happened.
