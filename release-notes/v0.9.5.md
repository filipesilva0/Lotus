Paste or drop as many images and files as you like on any page, an Images folder per generation with Reference and Output files, and fixes for voices and images with Lotus's own engines.

## New
- **Paste and drop everywhere**: press Ctrl+V (⌘V on a Mac) or drop files anywhere on Chat, Work, Images, Voice or the island. Every file is attached, not just the first. Copied text still pastes as text.
- **Several reference images on Images**: add up to 8. FLUX.2 uses all of them. Other models start from the first one; Use First picks another.
- **One folder per generation**: Lotus Studio/Images now has a folder for each generation, named after its prompt, holding Reference 1, Reference 2… and Output 1, Output 2…. Images made before 0.9.5 stay in their month folders.
- **Several recordings in Speech to Text**: drop or choose as many as you like; they are written down one after another. Text files dropped on Voice go into the Speak box.

## Fixes
- **Voice with Lotus's own engine**: Kokoro and Piper voices couldn't speak because sherpa-onnx 2.0 removed the part that pronounces words. Lotus now uses sherpa-onnx 1.13.8. If you installed 2.0, click Update in Settings → Models → Lotus Engines. Error messages now show the real cause.
- **Images on 8 GB graphics cards**: Lotus no longer passes a setting that switched off the image engine's own memory fitting, which made SDXL fail with "out of memory". When memory really runs out, the message says how much was needed and how much was free.
- **Drag and drop in the desktop app**: files dropped on the window now reach the page (the window took drops itself before).
