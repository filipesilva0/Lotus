Lotus is getting ready for the Microsoft Store: every release now also builds a Store package.

## Microsoft Store package
- Each release now includes `Lotus-windows-x64.msix`, the package that goes to the Microsoft Store. The Store signs it, so Lotus from the Store installs without the "Windows protected your PC" warning. This file is for the Store, not for installing by double-click: keep using the installer (.msi) or the portable zip from this page.
- A copy of Lotus installed from the Store is kept up to date by the Store. Its Updates page says so instead of downloading from GitHub.
- Copies installed from this page (the .msi or the portable zip) keep Lotus's own "Check for updates" button, as before.

## Privacy page
- Lotus now has a short privacy policy ([PRIVACY.md](https://github.com/filipesilva0/Lotus/blob/main/PRIVACY.md)): Lotus collects nothing, and it lists the few things that go online only when you switch them on.
