Calls sound right and answer sooner, voice effects work, GPT-SoVITS installs with one click on Windows, and the memory bar stays inside the message box.

## Calls
- **No more repeated words.** The Echo effect is left out of calls (it repeated each word and sounded like you talking over Lotus), sentences you already heard are not spoken again when Lotus corrects its answer, and a slow PC no longer plays the first answer twice.
- **Lotus notices sooner that you stopped talking.** It learns how loud your room is (fans, a busy PC, a loud microphone) and only counts sound clearly above that as speech, so a call no longer waits 45 seconds for a pause. This also works while the window is minimised.
- Calls use your voice's effects plus the ones set on the Speak page (without Echo and fades).

## Voice
- **Effects work on the Speak page.** Before, every setting went back to off, so a voice's own effects never played there.
- **Install GPT-SoVITS with one click (Windows).** Voice → Voices → Make a Voice has an Install GPT-SoVITS button that shows the download size, checks you have space, downloads the official package (RTX 50 cards get their own build), unpacks it and makes it ready to copy voices. Remove deletes it again. On Mac and Linux you can still point Lotus to a folder you set up yourself.
- **GPT-SoVITS starts reliably.** Lotus starts it the way its own launcher does, so Chinese log lines, other Python installs, accented folder names and another program on port 9880 no longer stop it. Errors say what went wrong in plain words.

## Fixed
- The thin memory bar at the top of the message box no longer sticks out past its right edge.
