Lotus runs better on everyday graphics cards: chats stay quick on 8 GB cards, "Think off" really turns thinking off, Web search only searches when it helps, and Work jobs cut short by a restart can be started again.

## Faster and steadier chats
- **Think off works**: with Think off, models that can reason step by step (like Qwen 3) now answer straight away instead of thinking first.
- **No more model swapping**: after each reply Lotus used to load a second model to name the chat and update memory, then load your chat model back. It now does that work with the model that is already loaded, so the next message starts at once.
- **Sized to your graphics card**: Lotus now picks how much of the conversation the model holds at once (its "context") from your card's free memory, so long chats no longer spill out of an 8 GB card and slow to a crawl. The instructions Lotus sends with every message are also shorter, which saves room and time.

## Smarter Web search
- With Web on, Lotus first decides whether your message needs a search at all. "Thanks!" no longer triggers one, and follow-up questions are searched with the conversation in mind.
- The new **Lotus Search** (the default) tries DuckDuckGo, then Bing, then DuckDuckGo Lite, then Wikipedia. When a site asks for a captcha, Lotus moves on to the next one and gives that site a rest for a while.

## Work
- A Work job cut off because Lotus or your computer closed now shows **Interrupted** with a **Try again** button, instead of saying "agents working" forever.

## Fixes
- The image progress bar moves smoothly: it shows Loading model, then Step n of N, then Finishing, instead of jumping back and forth.
- Picking a Photo example in Images switches to a photo-style model if the selected one only draws anime or art.
- Qwen 2.5 Coder models can use tools again (they write tool calls in a slightly different way, which Lotus now understands).

## Clearer wording about accounts
- Lotus is local-first and never needs an account. Signing in is optional and only keeps your profile in sync between PCs, through a sync server you set up yourself. The app and the README now say this plainly.
