Lotus tells the truth about what worked: agents only say Done when they really finished, web search falls back and backs off properly, and the whole app looks and behaves the same everywhere.

## Fixed: honest status
- **Agents say "Done" only when they really finished.** An agent that runs out of steps or never answers now says it couldn't finish and why (for example "all the web searches failed"), instead of a green check.
- **Web search falls back properly.** Wikipedia accepts Lotus again, so when DuckDuckGo asks for a captcha the search moves on to Bing and Wikipedia. When every search engine refuses, Lotus pauses for a few minutes instead of asking again and again. An agent stops searching after two failures in a row. The error message says what each engine answered.
- **Search queries are cleaner.** Formatting like `**bold**` is removed, and long messages are cut down to their key words. A search that finds nothing shows grey, not green.
- **Temperature:** a warning appears above 1.2, with a "Reset to 0.7" button. A setting left at 2.00 goes back to 0.7 once.
- **Question cards** that ask for a typed answer show as a card instead of raw text.
- **Chats get their name** after the first reply again.
- **Video memory card:** "Plenty free" only when the model fits. New installs pick a chat model that fits the graphics card. The settings, the card and Work all agree on how many agents run at once, and Work explains why some wait their turn.

## Fixed: smaller bugs
- Undo for deleting tasks, routines, skills, memories, images, styles, story lines, tool servers and projects.
- Learned skills are only used when they match the message.
- Stop says what had finished, and "keep going" continues from there.
- ComfyUI model folders are no longer doubled. Storage lists Lotus Studio/Models.
- The file picker opens in front of Lotus and gives focus back.
- In the Images sidebar, row actions no longer cover the title.
- No "Run with Lotus" button on tasks assigned to you. Activity shows the right type, with plain titles.
- Tooltips no longer show as empty boxes or get cut off.
- "1 microphone", "1 item", "1 memory".

## Consistent and accessible
- The assistant has one name everywhere: the one in its Soul.
- Chat, Work and Images share one message box layout.
- Models and voices show friendly names.
- Settings is a larger window with a list of sections on the left.
- Delete buttons look the same everywhere.
- Text contrast is higher, and selected chips are easier to see.
- Row actions work from the keyboard: F2 renames and Delete deletes.
